# Geonosian Canonical Lexicon

The full set of canonical words and morphemes. Geonosian has very few synonyms — words apply broadly. When in doubt, stretch a canonical word before inventing.

## Core nouns

| Geonosian | English | Range of use |
|-----------|---------|--------------|
| `JUST` | warriors | All armed forces; soldiers; combatants; the warrior caste. |
| `ABOOT` | enemies / Jedi | Literally "sword enemies." Generic enemy term, often used as an insult. Use for any opponent of the hive. |
| `POLKA` | weapon | Any weapon — sword, blaster, droid army. |
| `TICAL` | large/super-weapon | Intensifier for weaponry. A weapon scaled up beyond ordinary war. |
| `POLITICAL` (`POLKA` + `TICAL`) | huge-weapon-weapon | Idiomatic for planet-killer-scale devices (e.g., the Death Star). Also used loosely as "mighty / impactful." |
| `VOTE TITO` | everyone | The collective; the assembled hive; all present. |
| `KOOL` | underground | The hive's domain; literal underground; by extension, the hive itself. |
| `KURKA` | death | Death, finality, ending. |
| `BARA HYUNDAI` | sacred ritual combat / sacrifice | The cultural substitute for "executions" or institutional killing of prisoners. Never translate "executions" literally. |

## Core verbs

| Geonosian | English | Range of use |
|-----------|---------|--------------|
| `AIE` | speak / talk / communicate | All discourse — talking, debate, broadcast, conversation, declaration. |
| `OD` | witness / behold / watch | Visual attention with reverence or gravity. Also "honor" by extension. |
| `GUI` | now / begin / occurring | Marks present action or onset. Often functions as an aspectual particle. |
| `HOLE` | retreat | Withdraw, flee, fall back. |
| `LAVA` | command / curse | Imperative marker AND expletive — the same word for "I order" and "damn it." Context disambiguates. |
| `SEEKIN` | find | Search, locate, hunt. |
| `A` | go | Movement verb, often suffixed onto location nouns (`KOOL-A` = go-underground). |
| `QUIET DOLT` | silence / quiet | A two-word command for cessation of noise. |

## Particles and modifiers

| Geonosian | English | Notes |
|-----------|---------|-------|
| `OH SH SH SH` | immediately | Urgency adverb. Place near the verb it modifies. |
| `HE` | if / therefore | Conditional and consequential. Also used to mark questions when paired with rising tone. |
| `UNALUI` | I (unilateral command only) | Use ONLY for unilateral first-person commands. Otherwise, drop the pronoun. |

## Suffixes and morphology

| Affix | Function | Example |
|-------|----------|---------|
| `-NOA` | verb negation: "cannot" / "shouldn't" | `SEEKIN-NOA` = cannot find; `AIE-NOA` = cannot/shouldn't speak. |
| `INYURKA` | spiritual closing: "Amen" / "God help us" | Sentence-final, only on dire prophecies and prayers. |
| `K'-` (invention prefix) | constructed compound marker | Apostrophe-K prefix on invented compound nouns. Use sparingly and always flag in notes. |

## Punctuation

| Mark | Function |
|------|----------|
| `' '` (high-low click) | End of sentence with gravity, ritual, or theatrical suspense. |
| `''` (double click) | End of word of extreme importance or unilateral command. |
| `RRRRR...` (trill) | Sentence-opening attention call for formal/theatrical/prophetic statements. Lengthen the trill for greater drama. |
| Capital letters | Carry stress on a syllable. Most canonical words are fully capitalized as a romanization convention. |

## Cultural words to remember

- `BARA HYUNDAI` — the sacred festival of ritual combat. Always preferred over a literal gloss for "executions."
- `POLITICAL POLKA` — Death-Star-scale weapon. Use for any planet-killer or civilization-ending device.
- `QUIET DOLT` paired with `AIE` — "make discourse silent." The lofty register treats noise as a property of speech, not of bodies.

## Broad-application reminders

When you reach for invention, first check whether one of these stretches:

- **All communication** → `AIE`
- **All witnessing / reverence / attention** → `OD`
- **All weapons** → `POLKA`
- **All endings / finality / death** → `KURKA`
- **All movement** → `A` (often as suffix)
- **All warriors / armed personnel** → `JUST`
- **All enemies** → `ABOOT`
- **The collective / assembled people** → `VOTE TITO`
