# Worked Translation Examples

Read these to calibrate register, gap-handling, and the literal-gloss format. Each example shows the full output a translation should produce.

## Example 1 — Command (canonical)

**Input:** "Everyone retreat immediately!"

**Output:**

```
**LAVA OH SH SH SH VOTE TITO HOLE' '**

*Literally:* command — immediately — everyone — retreat (with terminal gravity).

*Translator's notes:* Pure canonical vocabulary. `LAVA` opens as the imperative expletive; the high-low click closes with command-weight. No trill needed — the command itself is the attention call.
```

## Example 2 — Casual sentiment with vocabulary gap

**Input:** "I love my parents."

**Output:**

```
**OD K'TITO**

*Literally:* behold the makers.

*Translator's notes:* Geonosian nobility has no canonical word for "love" or "parents" — the culture doesn't foreground tender sentiment. `OD` (witness/behold/revere) substitutes for "love" by stretching its range toward reverence. `K'TITO` is invented as a compound for "progenitors / makers." Pronoun "I" dropped (no command), "my" dropped (bulk). No trill or terminal click — the input is intimate, not theatrical.
```

## Example 3 — Prophetic / formal

**Input:** "Behold, the day of reckoning has come, and our enemies shall fall."

**Output:**

```
**RRRRR... OD' ' GUI KURKA-A ABOOT' ' INYURKA**

*Literally:* listen — behold (gravity) — now death-comes (to) enemies (gravity) — god help us.

*Translator's notes:* Full theatrical register. Opening trill for prophecy-framing. `OD` carries "behold." `GUI KURKA-A` constructs "now-death-goes" as a verbal phrase for "the reckoning comes" — `KURKA-A` is a compound (death + go) that stretches canonical roots rather than inventing a new word. `ABOOT` (sword-enemies) for "our enemies." `INYURKA` closes a dire prophecy. "Day of reckoning" abstracted into the death-arrives construction; literal "day" omitted as bulk.
```

## Example 4 — Question (uncertain)

**Input:** "Have the warriors found the enemy?"

**Output:**

```
**HE JUST SEEKIN ABOOT?**

*Literally:* if warriors find enemies (rising)?

*Translator's notes:* Geonosian has no formal question particle. The conditional `HE` ("if/therefore") frames uncertainty, and a rising final tone (rendered as `?` in romanization) signals interrogative. No trill, no terminal gravity click — questions are inherently unresolved and the high-low pattern is reserved for declarations.
```

## Example 5 — Heavy gap-handling (caveat needed)

**Input:** "Where did I leave my keys?"

**Output:**

```
**HE GUI K'KEX SEEKIN-NOA?**

*Literally:* if-now (the) small-locks find-cannot (rising)?

*Translator's notes:* Heavily invented — the hive court has no canonical vocabulary for personal property like keys. `K'KEX` is invented as a compound for "small-lock / opener," using the click-prefix invention pattern. `SEEKIN-NOA` is canonical (find-cannot suffix). The absence of "where" in the lexicon is approximated by the conditional `HE` plus the negated verb. **Caveat:** this translation is largely a fiction; a real Geonosian noble would simply not phrase such a thought, as menial possessions don't enter the lofty register.
```

## Example 6 — Unilateral command

**Input:** "I forbid you to speak of this."

**Output:**

```
**UNALUI AIE-NOA''**

*Literally:* I (commanding) speak-cannot (extreme).

*Translator's notes:* Pure unilateral command — exactly the case `UNALUI` is reserved for. `AIE-NOA` ("cannot speak / shall not speak") covers the prohibition. Double-click `''` closes with the extreme-importance marker, signaling this is decree, not request. No trill needed; `UNALUI` itself carries the command-weight. "Of this" omitted as bulk.
```

## Example 7 — Cultural substitution

**Input:** "Begin the executions."

**Output:**

```
**GUI BARA HYUNDAI''**

*Literally:* now (let begin) the sacred-ritual-combat (extreme).

*Translator's notes:* "Executions" is never translated literally — the cultural equivalent is `BARA HYUNDAI`, the sacred festival of ritual combat and sacrifice. `GUI` marks the onset. Double-click for the gravity of a unilateral command issued from the throne. No trill: the command is curt, ritualistic, and assumes the listener already understands the ceremony.
```
